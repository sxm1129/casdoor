# Casdoor 产品说明书 (Product Specification)

## 1. 产品简介
Casdoor 是一款界面美观、功能强大的身份及访问管理 (IAM) 单点登录系统。它的核心使命是帮助企业或开发者**免除“造轮子”的痛苦**，无需从零独立开发注册、登录、找回密码、绑定账号、授权等鉴权逻辑，一键将现代化的身份管理集成至自有的业务系统中。

通过它即插即用的 Web UI，企业可统一对用户池、企业组织架构进行一站式可视化管控。

## 2. 主要功能与产品亮点 (Key Features)

### 2.1 多协议支持与 SSO 单点登录
- 原生支持 **OAuth 2.0 / OIDC / SAML / CAS** 协议，这使得 Casdoor 既能作为“身份提供者(IdP)”，向内部子系统或者外部 SaaS 服务发放 Token，又能够与其他标准网关完美桥接。
- 用户在一处登录后，访问矩阵内所有关联应用都免除二次输入密码 (SSO)。

### 2.2 海量第三方登录提供商 (Providers)
- 国际化极佳：支持 GitHub、Google、Facebook、LinkedIn 等主流海外登录。
- 本土化深入：涵盖了微信扫码、微信移动端、QQ、钉钉、企业微信、飞书、微博、支付宝、Gitee、Bilibili 等国内全系社交与办公生态。
- 原生支持 **LDAP 和 Active Directory (AD)**，无缝集成企业已有的传统域控系统。

### 2.3 无密认证与多因素安全认证 (MFA)
- **无密码登录**：全面拥抱 WebAuthn，支持 Face ID、Windows Hello、YubiKey 等生物特征与硬件级认证。
- **多因素认证 (MFA)**：除密码外，系统预置了基于手机短信验证码、邮件验证码以及 TOTP 动态令牌 (Google Authenticator) 的强制双重挑战防护，全面满足等保 2.0 / 3.0 或金融级产品的合规要求。

### 2.4 强大的多租户架构与应用授权 (Multi-tenant IAM)
产品的后台按「组织(Organization)」-「应用(Application)」进行二维隔离：
- **组织管理**：允许企业划分不同的部门或者公司子体，每个组织下有独立的一套员工池。
- **应用授权**：各“应用”（如 OA系统、ERP系统、C端商城）可各自决定仅对特定的“组织”或第三方登录 Provider 开通使用权，精细化定制每个应用的登录体验(Logo，背景图，表单可选项)。

### 2.5 组织架构、角色与权限管理 (RBAC & Groups)
除了单纯的身份核验，Casdoor 内核自带一套结构明确的管理台用于配置鉴权：
- **部门与组 (Group)**: 支持树状结构的部门构建，并配合飞书/钉钉企业通讯录自动同步。
- **角色 (Role) & 权限 (Permission)**: 管理员可动态建角（如`前端开发`,`财务总监`），分配页面或按钮级权限标记；基于底层的纯关系型映射网络（User-Role-Permission 高性能联查），这些权限最终会反映进 JWT Token 分发给各业务系统使用。

### 2.6 易于二次定制与开发者友好
- **界面高度可配**：无需改写代码，管理后台即可配置登录页面的 UI 元素（按钮样式、品牌 Logo、免责声明等）。
- **完善的后端 SDK 矩阵**：不仅支持 Java / Go / Rust / PHP / Node / Python 全系后端，还有基于 Vue / React 实现前端接入。
- **事件中心 (Webhooks)**：所有的用户产生、信息变更甚至登陆失败，都可以投递给 Webhook 服务，支持发送到松弛(Slack)、钉钉或自主开发的监听接口。

## 3. 典型使用场景 (Use Cases)
* **B2B SaaS 平台底座**: 作为云应用的统一账号注册分发系统、账单和计费系统的外围包裹器。
* **大中型企业内网门户**: 代替古老的 AD 进行多办公套件的流转入口（从飞书免密跳转入自研后台），避免员工频记密码。
* **独立开发者 / 快速原型的注册系统**: 最快只需 5 分钟的配置和几行调用，就可以给刚发布的网页集成“Sign In With Github/WeChat”并自带完整的个人资料编辑页面。
